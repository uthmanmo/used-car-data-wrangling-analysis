# used-car-data-wrangling-analysis
This project demonstrates core data wrangling techniques on a used car dataset using Python and Pandas. It covers tasks such as data cleaning, formatting, normalization, binning, and basic visualization. The final output includes a cleaned dataset ready for further analysis or modeling.

## 📌 Project Objectives

- Clean and format raw data
- Handle missing and inconsistent values
- Normalize units and data types
- Transform continuous variables using binning
- Generate basic visualizations for exploratory analysis

---

## 🛠️ Technologies Used

- Python 3
- Jupyter Notebook
- Pandas
- Matplotlib
- NumPy

---

## 📊 Summary of Work

- Converted all relevant columns to numeric or categorical types
- Handled missing data (replaced, dropped, or inferred)
- Applied binning to "horsepower" to simplify analysis
- Plotted distribution and count charts
- Finalized a clean dataset suitable for machine learning or statistical analysis
